# Fiches publiées

Dépôt généré par `ferramentas/publicar.js` (dépôt de travail privé) : ne pas modifier à la main.

* Chaque `.html` est une fiche autonome ; `index.html` les liste.
* Les pages demandent aux moteurs de recherche de ne pas les indexer (balise `robots`) et n'envoient aucune requête (politique de sécurité `default-src 'none'`).
* Aucune donnée personnelle : la progression reste dans le navigateur de chaque appareil.
